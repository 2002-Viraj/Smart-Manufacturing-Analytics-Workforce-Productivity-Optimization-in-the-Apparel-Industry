## 📌 Project Overview

This project focuses on analyzing workforce productivity and operational efficiency in the apparel manufacturing industry using Statistical Analysis, Machine Learning, Forecasting, and Business Intelligence techniques.

The study aims to identify key factors affecting workforce productivity, predict productivity performance, and develop an interactive dashboard to support data-driven decision-making in manufacturing environments.

---

## 🎯 Project Objectives

### Main Objective

To develop a Smart Manufacturing Analytics Framework for analyzing workforce productivity and operational efficiency in the apparel manufacturing industry.

### Specific Objectives

✔ Analyze workforce productivity and operational performance

✔ Identify factors affecting workforce productivity

✔ Examine relationships between overtime, incentives, idle time, workforce size, and productivity

✔ Compare productivity performance among departments and teams

✔ Develop machine learning models for productivity prediction

✔ Create an interactive Power BI dashboard for managerial decision-making

## 🔑 Key Findings

### ✔ Actual Productivity Exceeded Targeted Productivity

Workers generally achieved expected productivity levels.

### ✔ Targeted Productivity is the Strongest Predictor

Higher productivity targets were associated with higher actual productivity.

### ✔ Incentives Positively Influence Productivity

Employees receiving incentives showed better productivity performance.

### ✔ Idle Time Negatively Affects Productivity

Increased idle time reduced workforce efficiency.

### ✔ Overtime Has No Significant Impact

Overtime alone does not significantly improve productivity.

### ✔ Productivity Remains Consistent Across Working Days

ANOVA results showed no significant differences among working days.

### ✔ Machine Learning Supports Productivity Prediction

The Random Forest model achieved satisfactory predictive performance.

### ✔ Business Intelligence Improves Decision-Making

Power BI dashboards provide real-time productivity insights.
